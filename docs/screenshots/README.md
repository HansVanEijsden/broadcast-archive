# Screenshot provenance

All screenshots in this folder were captured from the live Salland1 installation
of this plugin on **2026-11-25**, with Chrome driven by Playwright, at a 1×
device pixel ratio. They show real broadcast data from
`https://archive.salland1.nl/podcast.php`; no demo or synthetic content was
substituted.

| File | Viewport | State |
| --- | --- | --- |
| `desktop.png` | 1280 × 900 | Page at the top, first broadcast playing in the transport. |
| `mobile.png` | 390 × 844 | Page at the top, transport open, no floating site widgets visible (the transport paints above them). |
| `details.png` | 1280 × 900 | First broadcast expanded: actions, description and playlist. Scrolled so the details panel is visible. |

The surrounding header, sidebar and footer belong to the Newspaper theme and
the Salland1 site, not to this plugin. They are included to show the plugin in
its real context.
